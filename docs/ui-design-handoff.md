# IELTS 英语高效学习助手 — UI 设计交付文档

供 UI 设计 Agent 使用。本文档描述当前产品的全部用户可见功能、页面结构、状态流转和交互规则。

---

## 一、产品定位

面向雅思考生的英语学习 Web App。核心闭环：**学新词 → 记住它 → 复习巩固 → 练口语 → 看进展**。

- 当前为 MVP 阶段
- 数据存在浏览器 localStorage（无需登录）
- AI 由 DeepSeek 驱动
- 部署在 Vercel（公网可访问）
- 桌面和移动端均需可用

---

## 二、页面结构与导航

```
/                  首页（功能入口 + AI 对话）
/learn             新词学习
/review            今日复习
/speaking          口语训练
/report            学习报告
```

导航规则：
- 用户主入口是首页，通过四张功能卡片或 AI 对话进入具体功能
- 各功能页左上角有"← 返回"回到首页顶部
- 从功能页返回首页时，页面停在顶部（不自动滚到聊天区域）
- 无全局导航栏（首页即为 hub）

## 三、首页 `/`

### 布局结构

```
┌────────────────────────────────┐
│ Header                          │
│   产品名（大标题）              │
│   一句 slogan                   │
├────────────────────────────────┤
│ 核心能力（四张功能卡）          │
│   ┌──────┐  ┌──────┐          │
│   │新词学习│  │今日复习│          │
│   └──────┘  └──────┘          │
│   ┌──────┐  ┌──────┐          │
│   │口语训练│  │学习报告│          │
│   └──────┘  └──────┘          │
├────────────────────────────────┤
│ 和学习助手聊聊                  │
│ ┌──────────────────────────┐  │
│ │ 对话消息流（固定高度 400px）│  │
│ ├──────────────────────────┤  │
│ │ 输入框 + 发送按钮         │  │
│ │ 清除对话（小字链接）      │  │
│ └──────────────────────────┘  │
└────────────────────────────────┘
```

### 功能卡片

| 卡片 | 标题 | 动态副标题 |
|---|---|---|
| 新词学习 | 新词学习 | "输入单词或语块，生成词卡并完成主动回忆" |
| 今日复习 | 今日复习 | 有到期："X 个表达需要巩固 · 约 X 分钟"；无到期："今天暂时没有需要复习的内容" |
| 口语训练 | 口语训练 | "文字版口语练习，每轮聚焦一个改善点" |
| 学习报告 | 学习报告 | "查看最近的学习情况、需要关注的内容和下一步建议" |

卡片交互：点击跳转对应页面。Hover 有轻微阴影/边框色变化。

### AI 对话模块

**空态**：
- 居中文字："直接输入或选择一个话题开始"
- 四个快捷按钮（pill 形状）：学一个新表达 / 复习最近内容 / 练一会儿口语 / 看看学习情况
- 点击快捷按钮 = 发送对应消息（进入对话流）

**对话态**：
- 用户消息：靠右，品牌色背景圆角气泡，白色文字
- AI 消息：靠左，浅灰背景圆角气泡，深色文字
- AI 可返回：
  - **选择卡片组**：一组 pill 按钮，点击后作为用户新消息继续对话
  - **任务卡片**：带颜色的小卡片，点击跳转功能页（绿=学习，蓝=复习，紫=口语，黄=报告）
- 加载中：三点跳动动画（靠左）
- 输入框：多行文本，自动增高（最大 ~100px），Enter 发送，Shift+Enter 换行
- 发送按钮：圆形，品牌色
- "清除对话"：输入框下方小字链接

**滚动规则**：
- 对话区域内部滚动（不影响页面位置）
- 新消息自动滚到底部（仅在用户主动发送后触发，页面加载时不触发）

## 四、新词学习 `/learn`

### 页面流程

```
输入词条 → 加载词卡 → 展示词卡（含义隐藏）→ 用户回忆作答 → 提交 → 反馈结果
```

### 状态与界面

**1. 空态**
- 输入框 + "查词"按钮
- 提示语：可输入任何英文单词或语块

**2. 加载中**
- Spinner + 文字："正在查找词条…不在本地词库时将由 AI 生成词卡（约 5-15 秒）"

**3. 词卡就绪**

词卡组件结构：
```
┌──────────────────────────────┐
│ 单词/短语（大号粗体）          │
│ 音标  词性标签  类型标签        │
├──────────────────────────────┤
│ [点击查看核心含义] ← 按钮     │
│  或                           │
│ 核心含义（绿色背景卡片）       │
├──────────────────────────────┤
│ 使用场景：...                  │
│ 常见搭配：A、B、C             │
│ ┌─ 例句 ─────────────────┐  │
│ │ 英文例句                 │  │
│ │ 中文翻译（灰色）         │  │
│ └─────────────────────────┘  │
│ ⚠️ 易混淆：...               │
└──────────────────────────────┘
```

核心含义交互：
- 默认隐藏，显示为黄色按钮"点击查看核心含义（记为使用提示）"
- 点击后展开绿色含义卡片，且标记 `usedHint=true`（不可撤回）

回忆任务：
- 蓝色背景区块
- 提示语："请回忆「xxx」的核心含义（中文）"
- 多行文本输入框 + 提交按钮

**4. 已学过提示**
- 如果该词之前学过，词卡下方显示蓝色小提示："你之前已经学过这个词条。再次练习会创建新的学习记录。"

**5. 反馈结果**

| 结果 | 颜色 | 标题 | 内容 |
|---|---|---|---|
| 无提示正确 | 绿色 | — | "非常好！无提示正确回忆。「xxx」= 含义" |
| 提示后正确 | 黄色 | — | "正确！使用了提示，下次试着独立回忆" |
| 错误 | 红色 | — | "不太对。核心含义是：xxx" |

反馈卡底部：
- 下次复习时间（自然语言："今天稍后" / "明天" / "X 天后"）
- 两个按钮："继续学习下一个" / "立即巩固"（跳转 /review?itemId=xxx）

**6. 未找到**
- 黄色提示卡："词库中未找到「xxx」"
- 推荐可用词条
- "换一个词"按钮

**7. 错误**
- 红色提示卡 + 错误信息 + "重试"按钮

## 五、今日复习 `/review`

### 页面流程

```
加载 → 有任务则直接进入第一题 → 逐题作答 → 反馈 → 下一题 → 全部完成后总结
```

### 状态与界面

**1. 无任务空态**
- 居中展示："今天暂时没有需要复习的内容"
- 副标题："目前学过的表达还没到下一次复习时间。"
- 按钮："学习一个新表达"

**2. 复习中（单题）**

```
┌──────────────────────────────┐
│ 进入提示（仅第一题显示）：     │
│ "今天有 4 个表达需要巩固       │
│  · 预计约 2 分钟"              │
├──────────────────────────────┤
│ 进度条：1 / 4                  │
├──────────────────────────────┤
│ ┌─ 词条卡片 ────────────┐    │
│ │  单词/短语（大号居中）  │    │
│ │  "你还记得这个表达的     │    │
│ │   核心意思吗？"          │    │
│ └────────────────────────┘    │
├──────────────────────────────┤
│ [提示已显示] ← 黄色提示卡    │
│ "💡 提示：和「xxx」有关"      │
├──────────────────────────────┤
│ 输入框（Enter 提交）          │
│                               │
│ [查看提示]    [跳过] [提交]   │
│  左侧弱按钮   右侧弱  右侧主  │
└──────────────────────────────┘
```

操作说明：
- "查看提示"：点击后显示线索（关键词暗示），按钮变为"提示已显示"（disabled）
- 提示只给线索（如"和「减轻」有关"），不直接展示完整答案
- "跳过"：弱按钮，跳过该题
- "提交"：主按钮，禁用条件=输入为空或提交中

**3. 反馈卡**

| 结果 | 标题 | 副文本 | 颜色 |
|---|---|---|---|
| 无提示正确 | "记住了 👏" | "你这次可以不看提示回忆出核心意思。" | 绿色 |
| 提示后正确 | "在提示下想起来了" | "核心意思已经找回来了，不过这次还需要一点帮助。" | 黄色 |
| 错误 | "这次还没完全想起来" | "先重新看一下核心意思，之后会更快再次遇到它。" | 红色 |
| 跳过 | "先放一放" | "这个表达之后会再次安排复习。" | 灰色 |

反馈卡内容：
- 白色半透明卡片展示："xxx = 核心含义"
- 底部小字："下次复习：今天稍后 / 明天 / X 天后"
- 全宽按钮："下一个"（最后一题为"查看总结"）

**4. 总结页**

```
┌──────────────────────────────┐
│ "今日复习完成"（居中标题）     │
│ "共复习 4 个表达"              │
├──────────────────────────────┤
│ 四格统计卡（2×2 或 4×1）      │
│  独立想起来 │ 使用提示         │
│  还需巩固   │ 跳过             │
├──────────────────────────────┤
│ "还值得再看看："               │
│  [词条A] [词条B] [词条C]      │
│  （pill 标签，红色边框）       │
├──────────────────────────────┤
│ [继续复习] [学一个新表达]      │
│ [返回首页]                    │
└──────────────────────────────┘
```

## 六、口语训练 `/speaking`

### 页面流程

```
选题型 → 看题目 → 写英文回答 → AI 分析 → 查看微训练 → 可选重答 → 完成
```

### 状态与界面

**1. 选题**

三张卡片（网格排列）：
| 卡片 | 标题 | 说明 |
|---|---|---|
| 左 | 轻松热身 | 日常简答（40-80 词） |
| 中 | 完整表达 | 2 分钟独白描述（100-200 词） |
| 右 | 深入讨论 | 观点论证（80-150 词） |

**不向用户暴露 Part 1/2/3 内部分类。**

**2. 作答界面**

```
┌──────────────────────────────┐
│ ┌─ 题目卡 ─────────────────┐│
│ │ [P1] Daily Routine        ││
│ │ 英文题目（粗体）          ││
│ │ 中文翻译（灰色）          ││
│ └───────────────────────────┘│
├──────────────────────────────┤
│ 标签："首答" 或 "重答"        │
│ 多行文本输入框（6 行）        │
│ 右下角小字：XX 词             │
│ [提交回答] 按钮               │
└──────────────────────────────┘
```

**3. 分析反馈**

```
┌──────────────────────────────┐
│ ┌─ 分析结果 ───────────────┐│
│ │ "分析结果"（小标题）      ││
│ │ 总结一句话                ││
│ │ XX 词 · XX 句 · X 连接词  ││
│ └───────────────────────────┘│
├──────────────────────────────┤
│ ┌─ 主要问题（黄/绿色卡片）─┐│
│ │ [维度标签] [严重度标签]   ││
│ │ 问题描述                  ││
│ │ 改善建议（粗体）          ││
│ └───────────────────────────┘│
├──────────────────────────────┤
│ [查看微训练] [重新回答]      │
│ [跳过重答，结束]             │
└──────────────────────────────┘
```

**4. 微训练卡**
- 蓝色背景
- 标题："微训练"
- 练习提示（文字）
- 参考改善示例（斜体）
- 按钮："尝试重答" / "跳过，结束"

**5. 完成态**
- "本次口语练习完成"
- 主要改善点回顾
- 如有重答：显示重答后的新总结
- "再练一题"按钮

## 七、学习报告 `/report`

### 布局：纵向板块式

**空态**：
- "暂无学习记录" + "学习一个新表达"按钮

**有数据时的四个板块**：

**板块 1：概览**
- 三个数字卡（水平排列）：已学习表达 / 待复习 / 口语练习次数

**板块 2：词汇与记忆**
- 三个内联数字：可独立回忆（绿）/ 需要提示（黄）/ 还需巩固（红）
- 具体词条列表（最多 5 个）：词条名 + 原因（如"上次回忆不成功，需要加强"）

**板块 3：复习情况**
- 自然语言评估（一句话，如"还有一些内容需要巩固"）
- 复习次数 + 正确率

**板块 4：口语表现**（仅有练习数据时显示）
- 完成次数
- 最近主要问题
- 标记是否"反复出现"（>=2 次用黄色高亮）

**板块 5：推荐任务**
- 标题："接下来最值得做"
- 最多 3 条推荐卡片
- 每条含：标题 + 基于真实数据的原因 + 跳转按钮

## 八、设计约束

### 禁止展示

- 任何内部状态码（CORRECT_INDEPENDENT、RECALLED_WITH_HELP 等）
- 算法参数（+3 days、+4 hours、nextReviewAt ISO 字符串）
- 开发信息（P0/P1/P2、trace_id、intent、JSON、Provider 名称）
- 雅思分数（Band 5/6/7/8）
- "掌握率百分比"或"综合分"
- IELTS 高频/低频判断
- Part 1/2/3 等内部分类（口语用"轻松热身/完整表达/深入讨论"）

### 时间显示规则

| 实际间隔 | 用户看到 |
|---|---|
| < 12 小时 | 今天稍后 |
| 12-36 小时 | 明天 |
| > 36 小时 | X 天后 |

### 色彩语义

| 语义 | 使用场景 |
|---|---|
| 品牌色（蓝/青） | 主按钮、输入框焦点、AI 名义、进度条 |
| 绿色 | 正确/成功/独立回忆 |
| 黄色/琥珀色 | 提示/警告/需要提示的回忆 |
| 红色/玫瑰色 | 错误/失败/还需巩固 |
| 灰色 | 跳过/次要信息/禁用状态 |
| 蓝色（浅） | 微训练/信息提示/已学过提醒 |
| 紫色 | 口语训练相关卡片 |

### 响应式

- 桌面：最大宽度 ~768px 居中
- 移动端：全宽，按钮适当增大触摸面积
- 所有功能在移动端必须可用

### 无障碍

- 输入框有 label
- 按钮有明确文字（非纯图标）
- 颜色不作为唯一信息载体（配合文字/图标）

## 九、数据流简要说明（供设计参考）

- 所有学习数据存在浏览器 localStorage
- 刷新/关闭浏览器后数据保留
- 不跨设备同步
- 新词学习产生的数据直接影响今日复习和学习报告
- AI 对话历史也存在 localStorage（最多 50 条）
